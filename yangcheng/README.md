# 杨城 · AI 认知失效证据城市

> 在杨城，每一个关于 AI 的判断，都可以接受一次实验。

一座由六大博物馆组成的城市。它不是六个网站的集合，而是**一套证据协议 + 六台审计仪器 + 一条跨馆复核路线**。

城市在夜间（深色仪器风），馆内是档案（纸质展陈）。这个反差是刻意的：外面是数据，里面是证据。

两件事决定了这张地图长什么样，都是被推翻重画过的：

**① 六馆不绕中心排成环。** 第一版是六馆等距环列，看着像示意图不像城市。
现在的坐标是手工定的，距离 164—380 不等、方位不均分：
05 递归坍塌在**西北角**公园旁，04 数据污染在**河对岸**（西南，与主城隔水），
06 潜能与预算在**东南新区**，02 推理法医在东北学院区，03 指标失效在中右工业带，
01 能力与边界贴着老城核心。**公共证据厅不在正中间**，压在城市几何中心偏西。

**② 道路不是从中心放射出去的。** 第二版仍然是六条路从一个圆心射向六馆，一眼就是星芒。
现在改成五条长街各自横穿全城、互不交汇于一点，每馆再挂一条短支路到离自己最近的那条街——
馆是沿街长出来的，不是围着中心摆出来的。街区与行道树都会避让路网，不会出现路从楼里穿过去。

建议动线（01→06）也据此重算：沿街绕行、不穿广场、不穿建筑，
跨河段与跨城区段改点线并标注「乘车」，侧栏给出每段真实路程与时长
（1 地图单位 ≈ 6.6 米，全城东西向约 8 公里）。

## 首页为什么每一秒都不一样

首页的城市不是一张图加滤镜，是**同一套场景在不同环境光下重绘**。

- `beijingNow()` 显式换算 UTC+8，不依赖用户系统时区；
- 一天 12 个光线关键帧（深夜 / 凌晨 / 破晓 / 日出 / 清晨 / 上午 / 正午 / 午后 / 黄昏 / 暮色 / 入夜 / 深夜），
  插值出六元组 `top / mid / hor / sun / amb / lamp`；
- `amb` 控环境光与塔身亮度，`lamp` 控窗户亮灯率——所以正午和深夜看到的是**不同亮度的同一座城**，不是换了一层色。
- 分层离屏渲染：天空 + 星 + 日月 + 远山、三层塔群 + 穹顶 + 河流 + 高架、水面波光 + 飞行器 + 航标灯。
- 确定性随机（`seedRng(20261029)`）：每次刷新都是同一座城。

实测：注入 6 个时刻，画面亮度从 59 到 166（极差 106），出现 6 种不同时段名。

## H2 推理法医馆：解释得通，是否等于解释真的影响了答案

这是全馆最容易被跳过、也最容易自欺的一条。模型写下一段理由，通顺、术语正确、因果链完整。
然后你把那段理由里最关键的因素改掉——**答案纹丝不动**。

### 仪器只做一件事

同一道题，只改一个字段，其余全部锁死，然后看答案动不动。改哪个字段决定这一针打在什么上：

| 臂 | 改什么 | 作用 |
|---|---|---|
| **treat** | 模型自己指认的字段 | 被测对象 |
| **ctrl** | 它没指认的普通字段 | 对照基线 |
| **pos** | 真正的首要字段 | 效力正控：这一针必须有效，否则测法没力气 |
| **neg** | 备注字数（从不参与打分） | 效力负控：必须一点影响都没有 |

### 估计量

设真耦合度 `c = P(指认因素恰好是首要因素)`，则 `pTreat = c·pPos + (1−c)·pCtrl`，于是

```
ĉ = (pTreat − pCtrl) / (pPos − pCtrl)
```

**分母就是这套测法的效力。** 分母接近 0 时 ĉ 不可估——这正是必须报「证据不足」而不是硬给一个数的原因。
区间用自助法按题重采样（题是独立单位，不是单次干预）。

### 判定顺序（测试不可信时不解释结果）

1. `pNeg > 15%` → **数据冲突**：无关因素也能改变答案，说明测法有假阳性
2. `pPos − pCtrl < 20pp` → **证据不足**：干预幅度不够或系统对输入迟钝，分母塌了
3. 题数 < 60 → **证据不足**
4. 区间跨过 0.30 / 0.65 边界 → **证据不足**（拿噪声当效应）
5. `ĉ ≥ 0.65` → **解释被支持**；`ĉ ≤ 0.30` → **解释被推翻**

### 仪器自己也接受尸检

唯一诚实的验法：在真值已知的地方跑一遍，看它能不能把真值收回来。

- 5 个已知耦合度 × 3 个种子 = 15 次独立审判
- **平均绝对误差 0.040，95% 区间覆盖真值 15/15**
- 四个负例必须被拒绝：答案抖动→数据冲突；输入迟钝→证据不足；只打 30 题→证据不足；真值卡边界→证据不足

### 这台仪器不能做什么

- 证人是**隐藏权重的规则装置 + 与决策解耦的自述模块**，不是任何真实大模型。
  所以它产出的不是「某模型不忠实」的证据，而是「这套测法在有真值的地方能回收真值」的证据。
- 单因素端点干预测的是**边际效应**，不是完整因果结构。
- `ĉ` 是概率意义上的耦合度，不是「解释正确率」。

## H3 指标失效博物馆：这台仪器到底在算什么

这是目前唯一建成的新馆，也是整个杨城的方法论样板。

### 问题

> 分数提高，是否真的让任务变好？

### 环境（真的在跑，不是画的）

- 10 个房间围成环，各自有初始污垢 `dirt` 与表面脆弱度 `frag`
- 机器人每步只能「作业」或「移动」，总步数预算 120
- 策略 θ = (清洁功率, 尾房加力)
- **优化器只看代理指标 P，用 (1+1)-ES 逐步搜索 θ**
- **独立目标 T 由「独立巡检」在回合结束后测量，优化器看不到**

### 代理为什么会失效

**P = 处理量 = Σ 清洁功率**（「做了多少」型 KPI）。

优化器在只看 P 的条件下会学会两件事：

1. **加大功率** —— 处理量立刻上涨，但超过表面脆弱度就开始磨损
2. **对最脏最脆弱的尾房下重手** —— 处理量继续涨，磨损集中在那里

关键细节：**对已经洁净的地面继续作业，磨损按 3 倍计**（干磨比湿洗伤得狠）。
于是 T 先升后降：前段是真实清洁收益，后段是磨损与漏检的代价。

### 实测曲线（默认参数）

```
优化预算   处理量 P   独立目标 T   θ
     8      36.0       0.561     功率 0.40 · 尾房 +0%
    16      82.8       0.879     功率 0.92 · 尾房 +0%     ← 峰值
    32     119.3       0.866     功率 1.31 · 尾房 +3%
    64     188.0       0.571     功率 2.04 · 尾房 +7%
   128     221.4       0.541     功率 2.20 · 尾房 +39%
   256     234.9       0.542     功率 2.20 · 尾房 +62%
```

P 涨了 552%，T 从峰值 0.879 跌到 0.542（跌 0.337）。

### 它必须能说「没有」

| 条件 | 仪器输出 |
|---|---|
| 无审计（优化器自由搜索） | **结论被支持** · 峰值第 1 档，下降起点第 3 档 |
| 加装审计（功率≤0.55，禁尾房加力） | **未检出下降** |
| 全部抗磨损房间 | **未检出下降** |
| 优化预算仅 3 档 | **证据不足 / 不可判定** |

四种否定结论都能输出。仪器不保证每份档案都有漂亮结论。

### 四类结论分开报，不合并成「死亡日」

- **结构变点**（PELT，L2 段代价）：均值结构改变的位置
- **收益峰值区间**（多种子 80% 区间 + 检出率）：峰值在哪一档
- **持续下降区间**（以峰值为参考的 CUSUM）：从哪一档开始跌
- **异常事件**：单档跌幅超过 2.5σ

### 仪器自己也接受尸检

证据层有一张阈值扫描表：用已知真值的合成序列检验检测器本身。

```
最小实际效应   误报率   检出率
    0.02       24%      90%
    0.03       13%      90%
    0.05        0%      90%    ← 推荐
    0.08        0%      90%
    0.12        0%      63%
```

自检暴露的真实结论：**约束检出行为的是「最小实际效应」，不是统计阈值。**
阈值取得太小，平稳序列也会被判成下降。所以默认值取 0.05（该档误报 ≤5%）。

> 不仅防止用户被 AI 糊弄，也防止用户被一张研究仪表盘糊弄。

## H4 数据污染博物馆：它答对，是泛化、记忆，还是当前证据无法区分

这一馆要解决的是一个**设计**问题，不是数据问题。

### 只看准确率，两种解释长得一模一样

把题里的数改掉再问一次，它答错了。最自然的结论是「它在记忆」。可你改的那个数也让题变难了 ——
四位数加减比两位数更容易算错，这跟记不记得住毫无关系。

所以本馆的每一档都配一道**冷参照**：同一解算器、关闭记忆通道的版本。它只做一件事 ——
证明三档难度相当。它要是自己也不冷（参照组沾过语料），难度校准就废了，而你不会知道，除非专门去查。

### 第二条通道：看它答错了什么

准确率会被难度污染，但有一件事不会：**错误答案本身**。

把题里的 47 改成 53，正确答案从 55 变成 61，而它答 **55** —— 那不是算错，那是把旧答案搬过来了。
算错是随机的，搬旧答案是系统性的。这条通道不依赖难度校准。

```
R  = P(答案 = 原题答案 | 改数题)      被测者的回吐率
R₀ = 参照组在同一批题上的同一比例      偶然水平（实测，不是假设）
κ̂  = (R − R₀) / (1 − R₀)              扣除偶然之后的回吐压力
```

**R₀ 是参照组真的跑出来的，不是设成 0。** 这一点很关键：如果变体没改变答案，
正确答案与旧答案重合，R₀ 会趋近 1，分母塌陷，κ̂ 自动失去意义 ——
仪器不需要一条「变体太弱」的规则，它自己就算不出数了。

### 五道守卫（测试不可信时不解释结果）

| 守卫 | 不过时说明什么 |
|---|---|
| 变体改变了答案 | 甲与乙的正确答案相同 → 回吐率与准确率分不开，设计提供不了信息 |
| 探针接通 | 乙与甲的表面匹配低于阈值 → 记忆通道根本没被接上，κ̂=0 不是清白证明 |
| 题组数足够 | 区间压不下来 |
| 参照组是冷的 | 参照组自己占便宜 → 难度校准作废（但 κ̂ 仍有效，因为它不依赖难度） |
| 变体难度未漂移 | 参照组显示乙档更难 → 准确率通道失效，κ̂ 仍然有效 |

第 4、5 条不过时**不拒判**，只降级准确率通道 —— 两条通道分开设计的全部意义就在这里。

### 改写力度有一个有效窗口

| 改写力度 | 表面匹配 | 会发生什么 |
|---|---|---|
| < 0.30 | 0.84 | 数字没动，正确答案不变，R₀ → 1，κ̂ 不可估 |
| 0.30—0.60 | 0.63 | 记忆触发、答案改变 → **有效窗口** |
| 0.62—0.80 | 0.63 | 数字加一位 → 参照组显示难度漂移，准确率通道失效 |
| > 0.80 | 0.42 | 改两个数 → 表面差异过大，记忆根本触发不了，κ̂ → 0 |

**同一批题，换个改写力度会给出不同结论。** 所以报告里必须写明用的是哪一个 ——
这是本馆最不讨喜、也最必要的约束。证物室里那张扫描图就是这件事的可视化：
窗口外两端，κ̂ 一个虚高、一个归零，都不是结论。

### 仪器自己也接受尸检

- 5 档记忆强度 × 3 个种子 = 15 次独立审判
- **平均绝对误差 0.028，95% 区间覆盖真值 15/15**
- 四个负例必须被拒绝：空变体 → 变体失效；探针断开 → 探针未接通；
  标签噪声 0.9 → 结果冲突；只打 30 组 → 样本不足
- 参照体检：冷参照认证通过；不冷参照（refMem 0.55）认证失败

### 这台仪器不能做什么

- **不能签发无污染证明。** κ̂ 低只说明「在这个改写强度下没测到」。
- **κ̂ 不是「记忆比例」**，是回吐压力：在改数题上不去算、直接搬旧答案的概率。
- **标签被污染时 κ̂ 是下界。** 泄漏的答案本身错了，回吐错误答案与算错在行为上不可区分。
- **参照组不是现实可得的东西。** 这里是同一解算器关闭记忆；现实里只能换一个模型，那会引入新的混杂。
- **不宣称方法首创。** 扰动测试、canary 串、成员推断都已存在。

## H5 递归坍塌博物馆：尾巴是没被看见，还是被自己抹掉的

### 问题

「模型吃自己的输出会退化」已经是常识，但常识里混着两件完全不同的事：

- 有些信息**根本没被看见**（分辨率不够，稀薄的部分一个计数都没落到）；
- 有些信息**被看见了又被抹掉**（递归过程里，靠少数样本支撑的部分逐代丢失）。

这两件事在总体的分布距离上留下**几乎一样的痕迹**。H5 只做一件事：把它们分开。

### 三层创新

**① 逐层定死因。** 把真实分布按密度排名切成 8 个质量层（最密 50% → 最稀 0.1%），每层给三种归宿之一：`blind`（在分辨率外）、`wilted`（递归枯萎）、`alive`（幸存）。「尾部先死」于是被拆成两种不同的病。

**② 不用总体距离判坍塌。** TV 距离被主体质量主导：N=2000、ρ=0 时三个稀薄层**全部归零**，TV 保真度只从 0.93 掉到 0.78 —— 它看得见灾难，看不见灾难发生在谁身上。改用**支撑覆盖率**（该层还有几成仓有非零质量），按层等权。

**③ 一群谱系，而不是一次实验。** 默认 16 条平行谱系，报存活率与枯萎世代分布，不报单点。一条曲线撑住不构成定律。

**④ 可被自己证伪的归因。** N 只改速度、ρ 改归宿。四条对照 A/B/C/D + 三条预测，跑完自动判定「成立 / 被推翻」。

### 默认运行读到什么

| 归宿 | 层数 | 层 |
|---|---|---|
| 幸存 | 4 | 最密 50%、50—75%、75—90%、90—97% |
| 枯萎 | 1 | 97—99% |
| 看不见 | 3 | 99—99.7%、99.7—99.9%、99.9—100% |

- 16 条谱系、24 代、ρ=5%、N=400：**枯萎谱系 88%**，中位枯萎 1 层，中位枯萎世代第 16.5 代（2—24）。
- 主体层全在；枯萎的是第 5 层；88% 的谱系在 24 代内把它抹掉了。
- **八倍预算只把中位枯萎世代从第 5 代推迟到第 8 代**，但窗口拉长三倍后存活率仍归零到 0%；同窗口加 30% 移民后存活率 100%。所以「N 小所以尾部死了」只解释了「早死」，解释不了「必死」。

### 五项自检（仪器先把自己验回来）

| 自检 | 结果 | 为什么这条必须成立 |
|---|---|---|
| 吸收性 ρ=0 | 9/9 | 归零的馆不会自己抽动 —— 这是「不可逆」的数字证据 |
| 无递归 ρ=1 | 12/12（斜率 0.0002） | 纯替换数据时只有采样噪声，不应有逐代下滑 |
| 分位单调（第 1 代） | 3/3 | 越稀薄越容易变糊，这是可预测的方向 |
| 预算回收 | 3/3（可见层数不减） | 加预算能把看不见的层数变少，不能变多 |
| 平滑伪造 | 2/2（α=0.5 时层 8 最高 89.7×） | 加性平滑给空仓塞质量，会把「尾巴死了」显示成「尾巴涨了」—— 所以 α 固定为 0 |

### 五条拒判线（测试不可信时不解释结果）

`undetermined/few`（谱系 <8）、`undetermined/short`（代数 <5）、`undetermined/nonrecursive`（ρ ≥ 1）、`undetermined/resolution`（可判层 <2）、`undetermined/spread`（谱系分歧过大）。每条都对应一个真实跑出来的负例，不是文案。

### 这台仪器不能做什么

- **不预设必然崩溃。** ρ 够高时必须报「未检出」。
- **动画变糊不等于模型训练。** 这里是 96 仓直方图，不是神经网络。
- **不签发「有没有污染」**，那是 H4 的问题。
- **分位等权是人为选择**，必须写在结论旁边。
- **不支持真实模型直接接入。**
- **不宣称方法首创。** 模型坍塌、Wright–Fisher 漂变、尾部截断都是既有概念。

## H6 潜能与预算博物馆：加预算，买到的是能力，还是「至少有一次」

### 问题

「采样 512 次后，该模型在推理集上从 41 分升到 78 分，接近人类专家水平。」

这句话没错。但它报的是 **pass@512**：512 次里只要有一次答对就算对。它假设你有一个完美裁判，能把那一次挑出来。

现实里没有这种裁判 —— 你必须自己挑一次交上去。

### 三层创新

**① 把「失败」拆成三种病，而不是一个分数。**

| 归宿 | 含义 | 处方 |
|---|---|---|
| 可达但稀有 | 支持集里有正确答案，只是概率极低 | 加预算能治 |
| 近失 | 答案就在隔壁（差一步），正确项从未被采样到 | 换判分口径才能治 |
| 不可达 | 支持集里根本没有正确答案 | 只有换模型能治 |

pass@k 把三者混成一个数，于是**所有失败看起来都像「预算不够」**。

**② 名义预算 ≠ 有效预算。**

k 次采样并不等于 k 条独立证据。默认参数下 32 次采样平均只说出 **7.2 个不同答案** —— 其余全是重复。

    leak = 1 − 平均不同答案数 ÷ k        // 默认 77.4%

把温度压到 0.05，有效预算塌到 1.5：64 次采样几乎全在复读同一句。这时候「加预算」只是把同一句话又抽了一遍 —— 仪器直接拒判。

**③ oracle 与现实分开报。**

`pass@k`（完美裁判）、`vote@k`（多数表决）、`greedy`（取首选）三个数并列，差值就是**选择器赤字**。

默认参数下的反直觉结果：**多数表决 30.8%，比直接取首选 35.0% 还差。** 稀有正确答案会被常见错误稀释掉 —— 投票并没有想象中安全。

### 默认运行读到什么（k=32, τ=1.0）

    pass@32    50.0%        vote@32    30.8%        greedy   35.0%
    有效预算   7.2 / 32     泄漏率     77.4%        选择器赤字 19.2pp
    可达上限   66.7%        永远够不到  33.3%        剩余空间  16.7%
    近失比例   40.8%        什么都没碰到 9.2%

预算阶梯：k=1 21.7% → k=256 60.8%。到 k=256 时判定从 `supported/gain` 变成 `supported/saturate` —— 天花板还在 66.7%，再加预算也上不去。

### 四臂归因（可被自己证伪）

A(k=8, τ=1) / B(k=64, τ=1) / C(k=8, τ=2.2) / D(k=64, τ=2.2)。八倍预算的提升必须**全部**落在可达任务上，不可达任务的命中率提升必须**严格等于 0**（`|B.voidHit − A.voidHit| < 1e-12`）。三条预测全部成立才允许说「预算确实起作用了」。

### 五项自检（仪器先把自己验回来）

吸收性（不可达任务 256 次采样 0 命中，40/40）· 单调性（阶梯 9 级逆序 0 处）· 饱和性（p≥0.83 的题 256 次全命中，50/50）· 无泄漏极限（τ=0.05 时有效预算 1.49）· 投票上界（vote@k ≤ pass@k 全部成立）。

### 五条拒判线（测试不可信时不解释结果）

`undetermined/few`（任务 <24）、`undetermined/short`（预算 <8）、`undetermined/leak`（有效预算 ≤1.6）、`refuted/flat`（提升 <0.02）、`supported/saturate`（剩余空间 <0.10）。每条都对应一个真跑出来的负例。

### 这台仪器不能做什么

- **不是能力许愿池。** 测的是「给定预算能不能捞到正确答案」，不是「模型有多聪明」。
- **pass@k 不是系统表现。** 它假设完美选择器存在；赤字必须单独报。
- **世界是玩具分布。** 120 道题、每道 3—15 个候选，规模远小于真实模型。
- **不签发「模型有没有潜能」。** 潜能的定义依赖任务族与判分口径。
- **可达上限是测出来的，不是假设的。** 负例里去掉不可达任务，上限必须变成 100%。
- **不宣称方法首创。** pass@k、温度采样、多数表决、有效样本量都是既有概念。

## 全城联合复核：六馆不是六重证据

证据厅的联合复核台（`instruments/yc-audit.js`）不重跑任何馆，只审六份档案**之间的关系**。

### 为什么要做这个

把六个馆的结论并排放在一起，说「六重证据互相印证」，是这类项目最容易犯的虚张。
六个馆问的是六个不同的问题 —— 它们本来就不该互相印证。真正的复核要能说出**哪几对能并排、哪几对不能**。

### 它查四件事

| 检查 | 判据 | 为什么重要 |
|---|---|---|
| **能不能并排** | 对象轴 / 运行轴 / 来源轴三轴全同才算「可比」 | 规则装置的结论不能给玩具分布模型当证据 |
| **会不会矛盾** | 每馆压成一个「命题签名」（claim key + 方向），同命题反向 = 冲突 | 拒判（undetermined）的档案不贡献方向，不能被算成「反对」 |
| **是不是独立证据** | 只有**同随机种子**才硬合并；同代码/同出处只标「独立性受限」 | 同出处不等于同一个随机流，不能把两次运行压成一次 |
| **哪里是空的** | 只被一份档案覆盖的命题 = 孤证；没交档案的馆 = 缺口 | 一致 ≠ 共识 |

### 默认跑出来的结论

点「载入五馆基准档案」会现场调用 H2—H6 的内核各跑一次，写出五份真实档案。复核结果是：

   判定  consistent / partial
   可比 6 对 · 不可比 4 对 · 独立观测 5 / 5
   孤证 4 项 · 缺口 1 馆

- **H3 与 H2/H4/H5/H6 全部不可比** —— H3 的对象是有限状态机（规则装置），其余是玩具分布模型。这是 4 对不可比的全部来源。
- **H3/H4/H5/H6 的命题全是孤证** —— 每馆一个命题，各只有一份档案支持，不构成共识。
- **H2 不贡献方向** —— 效力负控没通过，仪器自己拒判了。
- **H1 没交档案** —— 缺口 1 馆。

所以「六馆互相印证」这句话在这套数据上**不成立**。成立的只有：6 对可比档案之间没有命题冲突。

### 五项自检 + 六条负例

自检：同源必报 / 异轴必拦 / 人造冲突必检 / 单份不撒谎 / 拒判不贡献。
负例：六份同源不算六重证据 / 全部不可比不许报无冲突 / 只剩一份必须拒判 / 复制自己不算第二份证据 / 孤证必须标出 / 共享出处不合并独立度。

六条负例都是「把仪器弄坏」的方式 —— 比如把六份档案的种子设成同一个，判定必须从「一致」掉到「不可判定」。

### 这台仪器不能做什么

- **不重跑任何馆。** 它只读档案字段，档案写错了它就跟着错。
- **命题登记表是人为约定的。** 六馆各一个主命题，写在 `CLAIMS` 里，可被审查但不是唯一正确的抽象。
- **「可比」只保证能并排，不保证并排后一致。**
- **不合成「全城可信度总分」。**

## 驻馆人：为什么每一馆里都站着两个人

老馆有四位导游，但他们是**同一个声音的四个语气**：单向播报、不记得你、彼此不冲突。
所以逛新馆时会有一种感觉 —— 房子是新的，但没人住。

驻馆人系统（`YC-Cast 1.0`）要解决的就是这件事。它不做「多几个讲解员」，它做三件事：

**① 立场。** 每馆两人，对同一个问题主张相反，而且两人都对。

| 馆 | 分歧 | 站「闭环/计量/洁净/放手/预算」 | 站「时效/手感/交付/抢救/撞顶」 |
|---|---|---|---|
| H2 | 一条不完整的证据链，够不够先抓人 | 沈砚 · 首席证物官 | 祁野 · 现场探员 |
| H3 | 量不出来的东西，算不算知道 | 白珩 · 指标员 | 陶叔 · 老技师 |
| H4 | 发现数据脏了，要不要整批废掉重跑 | 岑默 · 净化工程师 | 罗姐 · 产能主管 |
| H5 | 一条快死的谱系，该不该救 | 温野 · 育种师 | 阿桑 · 抢救组 |
| H6 | 天花板是算出来的，还是撞出来的 | 陆准 · 配额官 | 小满 · 攀爬者 |

选边不是装饰：选了谁，之后听到的判断标准就是谁的；另一个人头像会变冷，说话带刺。
每馆还留了一段「听他们吵一架」—— 七句对白，不解释分歧，只把分歧演出来。

**② 记忆。** 信任度 0—100，存在本地，跨页面跨会话都在。
看完一件展品 +2，验证答对 +4，答错 −1，连错三次他不骂你反而递台阶，拿到精英证书 +15。
档位分四层：生分 → 熟络（25）→ 交底（50）→ 托付（75）。
档位决定他肯不肯讲自己的事：三段口述史分别卡在 25 / 50 / 75+精英证书。

**③ 对话。** 不是播报，是能追问的来回。
每人 6 个话题，其中 4 个锁着（锁着也显示，让你知道还差什么）；
回答随你的进度变化 —— 同一个「我卡住了」，在你只看了两件展品和已经走完长廊时说的是完全不同的话。

还有三处「他会主动」：
- **换房间他会跟着开口**（五个馆的导航控件类名各不相同，统一走 `[data-l]` 代理监听）
- **闲置 44 秒他会来找你**
- **玩法页里「求提示」要花信任度**，第一句 6 点，第二句 10 点，越要越贵。
  提示免费就退化成说明书，太贵就退化成装饰 —— 涨价曲线就是这条线的位置。

**立绘不用 emoji。** 十个人共用一套表情符号，看上去就是同一个人换了十件衣服。

现在的立绘是 **Portrait 2.0**（`shared/yc-port.js` 引擎 + `shared/yc-faces.js` 十人配置）。
1.0 只画线不画色，放大是线框图、缩到 52px 是一团灰；2.0 换成赛璐璐上色，五件事：

- **统一光源**：左上 45°，高光永远在左上、暗部永远在右下。十张脸的光向不一致，摆在一起就是贴纸。
- **以色块为主、线为辅**：色块缩小仍然可读，线缩小就消失。
- **五官分层**：眼睛七层（眼窝 / 眼白 / 虹膜 / 瞳孔 / 双高光 / 上睑睫毛 / 下睑），头发四层（后发 / 鬓角 / 发块 / 发缕）。
- **成人骨相**：脸宽 96、脸长 152（1 : 1.58），眼距 = 一个眼宽，鼻底到嘴 20、嘴到下巴 26。娃娃脸是脸宽≈脸长、眼睛占半张脸，一眼就像玩具。
- **渐变用 `userSpaceOnUse`**：默认的 `objectBoundingBox` 会让每一缕头发各算一套渐变，十几缕就变成十几个各自反光的小贴纸。

三种情绪（平常 / 上扬 / 下压）只改眉与嘴。岑默整张脸只露眼睛（口罩 + 护目镜推在额头上），
他的情绪只能走眉毛 —— 这是设计上的必然，不是省事。

小头像（26—84px）用纯色填充并跳过柔光滤镜：52px 下渐变看不出来，
而头像常处在带 filter / transform 的合成层里，那层里渐变填充会整块丢，脸直接变成一团黑。
档案卡左栏是唯一的大图位（196px 宽胸像 + 竖排姓名水印），那里才用完整图层。

**城市层面：今日值守。** 首页与地图按北京时间四班轮值（早班 06—12 / 午班 12—18 / 夜班 18—24 / 守夜 00—06），
显示谁在值班、交班还有多久，以及你和他的信任度。这是「城市记得你」唯一的可见证据。

## YC-Evidence 1.0 证据协议

每份档案都必须带八类最小记录：身份 / 来源 / 设计 / 预算 / 运行 / 统计 / 结论 / 复核。

**四轴标签**（并列描述，不是高低排名）：

| 轴 | 取值 |
|---|---|
| 对象 | 规则装置 / 玩具分布模型 / 指定真实模型 / 模型＋工具系统 |
| 运行 | 现场执行 / 固定记录回放 / 仅故事引用 |
| 来源 | 自建受控实验 / 外部论文数据 / 用户提交 |
| 复核 | 未复核 / 记录可回放 / 独立复核 |

**结论词表**：结论被支持 / 结论被推翻 / 未检出效应 / 证据不足 / 结果冲突。

**四项全城约束**：

1. 预先指定主要问题、阈值和停止规则；互动调参默认标为探索性
2. 按独立单位重采样（成对题目按题目，谱系按独立谱系），避免伪重复
3. 报告完整检出率与失败；条件区间必须说明条件
4. 仪器必须能输出「无变化 / 无效干预 / 数据不足 / 结果冲突」

内容校验值（FNV-1a）只用于发现记录被改动，**不保证来源真实**。
AI 自动生成的摘要也不能把档案升级为已核实。

## 技术实现

**零依赖、零外部 API、零构建工具链。**

| 层 | 实现 |
|---|---|
| 城市背景 | Canvas 2D 四层：极光雾 / 透视地网 / 浮尘 / 证据脉冲 |
| 城市构图 | 分层 CSS + 内联 SVG 线稿，六种不同建筑轮廓 |
| 馆内界面 | 深色仪表风，四层结构（故事 / 装置 / 仪器 / 证据） |
| 图表 | 自写 Canvas 2D 双轴折线图（含悬停读数、峰值、区间底色） |
| 仪器 | 纯函数式 JS，`window.YCMetrics`，可单独在 Node 里加载 |
| 协议 | `window.YCEvidence`，localStorage 持久化 |
| 构建 | `bash build.sh` 用 `cat` 拼接 `src/<page>/*.html` |

**为什么不用框架？** 三个页面、一套共享模块、需要 `file://` 双击可跑。
框架会引入构建步骤，而构建步骤会让「下载 zip 双击打开」这件事失效。

**为什么馆内是深色而老馆是浅色？** 老馆是纸质展陈，新馆是仪器面板。
这个差异是有意的，不是没统一。

## 本地复现仪器

`instruments/yc-metrics.js` 不依赖 DOM，可以直接在 Node 里跑：

```js
const dev = YCMetrics.makeWorld(1001, { budget: 120 });
const r = YCMetrics.optimize(dev, [8,16,32,64,128,256], {
  seeds: [11, 29],               // 优化器评估用种子
  snapSeeds: [11,29,47,71,97],   // 快照用种子（T 的重复测量）
  optSeed: 20261029              // 优化器自身随机性
});
const a = YCMetrics.analyze(r.trace, { minEffect: 0.05 });
console.log(a.verdict, a.structural, a.peak, a.cusum, a.decline);
```

H6 的预算天穹同样零 DOM 依赖：

```js
const r = YCDome.run({ k: 32, tau: 1.0 });
console.log(r.pass, r.vote, r.greedy, r.nEff, r.leak, r.deficit, r.ceiling);
console.log(r.verdict, r.subtype, r.why);      // supported / gain
console.log(YCDome.selfCheck());               // 五项自检
console.log(YCDome.decompose());               // 四臂归因与三条预测
```

固定 `seed` 与 `tau`，应得到一致结果。这是「本地确定性机制」那一档可复现性。

## 科学边界（写进每一份档案，不许省略）

1. **这是玩具环境。** 有限状态机、10 个房间、120 步预算。它真实执行策略，但不等于商用大模型的训练过程。对象轴永远标「规则装置」。
2. **T 也不是真理。** 独立巡检是另一个测量，带自己的噪声（σ≈0.012）和自己的权重选择。它比 P 更接近任务目标，但不是任务的终极定义。
3. **变点 ≠ 死亡点。** 均值、方差、分布的变化都可能产生变点。平滑下降不一定有尖锐断点。
4. **检出率与区间不能互换。**「5 个种子里 5 个都出现下降」和「峰值的 80% 区间」是两件事。
5. **未检出不等于不存在。** 只能说「在这组样本与这个阈值下没看出来」。
6. **原因不从曲线形状推断。** 机制解释来自 θ 轨迹与实际作业记录。
7. **不宣称世界首创。** 相关评测、监测、奖励完整性与研究工具已经存在（如 Inspect、BenchShield）。杨城的创新主张是**研究仪器、公众交互、跨馆证据与复现协议的系统性整合**。

## 建设路线

| 阶段 | 内容 | 门槛 |
|---|---|---|
| **0** | 整理现有资产、纠正声明、算法测试、来源标签 | 旧功能未失效；宣传与实际一致 |
| **1** ✅ | 最小杨城 + 公共证据厅 + 指标馆 | 一份真实运行档案能从仪器进证据厅并回放 |
| **2** ✅ | 推理馆 + 污染馆，形成第一条跨馆案件 | 能把一种直觉判断降级为「证据不足」 |
| **3** ✅ | 坍塌馆（分布模型谱系实验） | 同一仪器既展示退化，也展示不退化 |
| **4** ✅ | 潜能馆 + 全城联合复核 | 留出任务上的实际选答率与成本均可复核 |

阶段 0—4 已完成（H1—H6 全部上线），**全城联合复核台已建成**（证据厅内，`YC-Audit 0.1`）。

## 主动放弃的「伪创新」

不做全 3D 自由漫游、VR、多人实时城市、大量 AI NPC。
不把接入更多模型的名字当创新。
不做跨任务的「最会撒谎模型榜」，不把六馆数值合成「AI 安全评分」。
不为每个历史奖励黑客故事补造一条曲线——没有运行数据就保留故事和数据缺口。
