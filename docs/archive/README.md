# 早期原型（存档，不参与构建）

这三份是**老馆建成之前**的一次性原型，用来先验证「一个页面能不能把一种 AI 失效讲清楚」。
它们后来被重做成了正式的展品，代码没有复用——保留在这里只是为了让这条线看得见。

| 文件 | 后来变成了 |
|---|---|
| `emergence-lab.html` | 展品 01 涌现与海市蜃楼（`m1-mirage.html`） |
| `horizon-workbench.html` | 展品 02 认证地平线（`m2-horizon.html`） |
| `certification-horizon.html` | 展品 02 更早的一版，只做到「证书值多少钱」 |

可以直接双击打开，但**它们不遵守现在的设计规范**：没有舱室外壳、没有三层结构、
没有统一配色，`localStorage` 的键名也是旧的，和正式版不互通。

`vendor/` 里那两个同名文件是它们的**补丁版**（构建时用 `sed` 改过路径，供 iframe 收编使用），
和这里的原件内容不同，不要混用。
