Proposition 9 · 可得 ≠ 可提取n = 4 示例
H₀ = X（原始比特） H₁ = (X₁…Xn−1, Y)
两种表示双射，且 I(H₀;Y) = I(H₁;Y) = 1 bit 但查询成本相差 n−1 倍

令 X 在 {0,1}n 上均匀，Y = ⊕j Xj。 两种表示 H₀ = X 与 H₁ = (X₁,…,Xn−1, Y) 互为双射——逆映射就是 Xn = Y ⊕ X₁ ⊕ … ⊕ Xn−1。 两者的互信息完全相同，都是一比特。

但任何自适应随机读取器，只要每次执行最多查询 n−1 个坐标， 对 H₀ 的预测错误率就恒为 1/2： 条件在任意叶子转录上，总有一个比特没被查到，把它翻转得到另一个同样可能的赋值， 而两者的奇偶性相反。对 H₁ 只要一次查询就精确。

// 可得性与提取成本是两个资源
I(H₀;Y) = I(H₁;Y) = 1 bit
err(H₀, q ≤ n−1) = 1/2  ·  err(H₁, q = 1) = 0

这个论证只关乎提取成本，与因果使用无关。产生 H₁ 的系统， 完全可以无视它的最后一个坐标。

在被动访问下 S = B = s。把两个系统耦合到同一组「保留/重置」决策 和同一组均匀抽样上，它们的续算状态每一步都相同， 因此任何数量的重置、任何自适应选择的无干预输入，其转录律都逐点相等。 先验相等时，每个被动二分类器的错误率至少 1/2，随机猜测即可达到。

这正是关键：接口本身不暴露接线或参数。 定理 2 的等式只关于被允许的运行时观测——两个机制的接线图、源码、梯度、权重、 侧信道时序都不必相同。这里没有主张任何白盒不可能性。

为什么 ℓ ≥ 1 是必须的

若允许 ℓ = 0，直接观测切口起始状态就会给出 r = 1，与学习完全无关。定理刻意研究 ℓ ≥ 1： 信号必须穿过一段未观测的续算。

写者只选择了一个当前状态；它没有提供未来答案，没有替换原生输出，也没有改动 B。

07 边界 · 论文自己划的线

什么会把这套结论
直接推翻

一篇理论文章的可信度，主要看它把失效条件写得多清楚。下面四条是论文 用命题形式固定下来的失败模式，不是脚注。

Prop 12扰动地板

ρℓ 一旦小于 2ℓξ，信号不可辨

若每个实际后缀核与理想核的行级 TV 距离不超过 ξ，则实际端点对比 r̃ 满足 |r̃ − ρℓ| ≤ 2ℓξ。 理想对比本身不再保证存在正的实际信号。

保留率 ρ0.85
行级扰动 ξ0.004
Prop 13置换结构

常数转移会抹掉被替换的状态

取任意符号，其规定转移是常数映射 f(s) = s*。 活状态 a₀ 与旁路状态 s 都确定性地到达 s*，端点律相同—— 尽管活系统确实把状态当作更新参数用了。 局部完全正确 + 语法上使用状态参数，都不保证端点可区分。 定理 2 的单射性恰好排除了这种坍缩。

Prop 14有限视野

有界长度测试不能认证无界行为

若声明的状态不保证包含全部内部记忆，就存在两个有限状态实现： 在该协议下转录完全相同，但在更长的轨迹上输出不同。 构造方式是一个隐藏计数器，在第 Lmax+1 步改输出。 这正是定理 7 的「完整状态 + 时齐马尔可夫」承诺所排除的。

§7保护是物理假设

写者若能改 B，归因立即失效

如果写者可以同时改 B 和 S，令 S = B = a₀， 旁路系统就会遵循与活系统相同的续算律， 把它归因给 S 的审计无效。同理，允许写者注入未来输出就能制造任意响应。 协议靠干预语义禁止这些操作，而不是靠正则项去「劝」。

这些结果校准的是显式访问与监督假设下的认证；它们并不建立语言模型中的算法发现， 也不建立普适的涌现相变。
Abstract · 原文末句 · 作者自我限制
被动不可区分不意味着什么

定理 2 的等式只关于被允许的运行时观测。两个机制不必拥有相同的接线图、源码、 梯度、权重或侧信道时序。观察这些对象可能在不使用规定统计检验的情况下识别出机制。 论文没有主张任何白盒不可能性定理。

局部证书是单边的

定理 7 是一个单边承诺检验：在 Hgood 下所有行精确， 在 Hbad(η) 下至少一行误差 ≥ η。它对精确零假设完备， 但对每个近似忠实的实现并不完备—— 行误差小而非零的模型仍可能被频繁拒绝。 想要「对噪声良好类高接受、对分离坏类低接受」，需要显式的无差异区间与二项检验。

09 对照 · 为什么单一 onset 分数不够

曲线上的拐点
不是计算上的证据

本页前一版是一个缩放曲线涌现检测器：在曲线上找变点、 用重标定判断「真台阶 vs 量纲假象」、用 BIC 在 linear/sigmoid/step 之间比模型。 它有用，但它回答的只是三种问题里的第一种的一个代理。

曲线变点检测
测的是评测分数随规模的形状——有没有跳变、跳变是否在换标尺后消失
接口只有 (规模, 分数) 两个外部量；无重置、无干预、无中间状态
能主张「在这条曲线上，某个尺度的跳变在重标定后仍然存在」
不能主张内部有某个寄存器被因果使用；更不能主张整条轨迹保真
典型失败非线性评测制造出表面不连续；反之，任务相关的内部特征可以在损失明显改善之前就形成
受保护切口认证
测的是一个声明的寄存器是否参与产生原生输出的计算
接口重置、可读/可写寄存器、受保护副本、规定的干预目标、输入后缀、原生端点
能主张「在误差 δ、视野 L、给定访问模型下，该寄存器被因果使用」
不能主张识别出唯一的程序；恢复未知表示；证明该变量在所有替代实现下都必要
代价信号 ρℓ 指数衰减 ⇒ 证据 Θ(ρ−2ℓ)；写入不足则完全不可检测
论文给出的方法论建议

一份关于「内部前兆」的报告，应当说明它测的是信息可得、 因果影响、还是组合正确性。 提高审计灵敏度可以让第一处可检测的影响提前出现，而学习器的能力毫无进展； 反过来，改善单步行为并不能消除长视野的误差累积。 有用的经验扩展应当保留这三类主张的区别，而不是用一个 onset 分数去拟合全部三者。
